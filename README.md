## Запуск

Достаточно Python 3.10 или новее. Модуль `sqlite3` входит в стандартную библиотеку.

```sh
git clone https://github.com/youworu/mtp-lab7-variant6.git
cd mtp-lab7-variant6
python main.py add "Машина времени" "Герберт Уэллс"
python main.py add "Солярис" "Станислав Лем"
python main.py list
python main.py find "Солярис" --plan
```

Файл `library.sqlite3` создаётся при первом запуске в текущей папке.
Чтобы выбрать другой файл, передайте `--db` перед командой.
Например, `python main.py --db example.sqlite3 list`.

Команда `list` выведет обе книги с авторами. В поиске нужно указать название
целиком и сохранить регистр. Для примера с «Солярисом» вывод получился таким.

```text
Солярис — Станислав Лем
План поиска
SEARCH books USING INDEX idx_books_title (title=?)
SEARCH authors USING INTEGER PRIMARY KEY (rowid=?)
```

Первая строка плана показывает поиск в индексе названий, вторая — получение
автора по первичному ключу.

## Таблицы и запросы

`authors` содержит уникальные имена авторов, а `books.author_id` ссылается
на `authors.id`. При добавлении книги существующий автор используется повторно.
У одного автора одинаковое название записывается только один раз. У разных
авторов могут быть книги с одинаковым названием.

Значения передаются в SQLite отдельно от текста SQL через параметры `?`.
Это позволяет хранить, например, имена и названия с апострофами. Список
и поиск получают название и имя автора одним запросом с `JOIN`.
Чтение здесь не меняет данные каталога.

## Тесты

```sh
python -m unittest discover -s tests -v
```

Десять тестов проверяют вставку, обработку повторов и пустых полей,
связь с автором, поиск и использование индекса. Большинство тестов
используют SQLite в памяти. Один тест сохраняет книгу во временный файл
и читает её после повторного открытия базы.

Документация [sqlite3](https://docs.python.org/3.12/library/sqlite3.html)
и [EXPLAIN QUERY PLAN](https://www.sqlite.org/eqp.html).
